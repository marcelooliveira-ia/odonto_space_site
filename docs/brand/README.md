# Identidade visual — ODONTO SPACE

A logomarca oficial é **monocromática**: preto `#201E1E` e branco. O site não usa cores de destaque.

## Arquivos
| Caminho | O que é |
|---|---|
| `docs/brand/original/` | Originais oficiais, **sem alteração**: prancha vetorial (PDF), logo branca (PNG 1146×1730), ícone 256×256 e `favicon.ico` |
| `public/images/brand/logo-preto.svg` | Versão preta (fundo claro), extraída do PDF vetorial |
| `public/images/brand/logo-branco.svg` | Versão branca (fundo escuro), extraída do PDF vetorial |
| `public/images/og-odonto-space.png` | Imagem de compartilhamento 1200×630: a logo preta centralizada, sem alteração de proporção |
| `public/favicon.ico`, `public/favicon.png` | Cópias dos arquivos oficiais |

Os SVGs foram gerados **sem redesenhar** o logotipo: apenas isolam cada versão da prancha oficial e removem um contorno de 0,57 pt (artefato da exportação que apareceria em fundo cinza). Proporção ≈ 0,80:1.

## Regras de uso
- Logo preta sobre branco/cinza claro; logo branca somente sobre `#201E1E`.
- Não recolorir, não esticar, não aplicar sobre fotografias.
- Existe uma versão horizontal apenas em raster (capa do Facebook); não é usada no site.

## Paleta
| Papel | Hex |
|---|---|
| Preto da marca | `#201E1E` |
| Grafite | `#353232` |
| Cinza texto | `#5F5B59` |
| Cinza suave (só sobre escuro) | `#8C8885` |
| Cinza linha / névoa | `#CFCCC8` / `#E6E4E1` |
| Papel / papel claro | `#F2F1EF` / `#FAF9F8` |
| Branco | `#FFFFFF` |

Contrastes (WCAG): preto/branco 16,6:1 · cinza texto/branco 6,7:1 · cinza suave/preto 4,7:1.

## Tipografia
Poppins (títulos, menu, botões) + Inter (texto corrido), ambas autohospedadas via Fontsource. Títulos em caixa alta, como na logo.
