# Identidade visual — ODONTO SPACE

## Arquivos
| Caminho | O que é |
|---|---|
| `docs/brand/original/` | Originais oficiais, **sem alteração**: prancha vetorial (PDF), logo branca (PNG), ícone 256×256 e `favicon.ico` |
| `src/assets/brand/logo-preto.svg` | Versão preta (fundo claro), extraída do PDF vetorial. Usada no cabeçalho e no rodapé |
| `src/assets/brand/logo-branco.svg` | Versão branca (fundo escuro), extraída do PDF vetorial |
| `public/og-odonto-space.png` | Imagem de compartilhamento 1200×630 |
| `public/favicon.ico`, `public/favicon.png` | Cópias dos arquivos oficiais |

Os SVGs foram gerados **sem redesenhar** o logotipo (apenas isolam cada versão da prancha oficial e removem um contorno de 0,57 pt). Proporção ≈ 0,80:1. Não recolorir, não esticar, não aplicar sobre fotografias.

## Paleta aprovada (medida nas artes oficiais de redes sociais)
| Papel | Hex |
|---|---|
| Ardósia | `#2F4A54` |
| Teal-ardósia | `#42646F` |
| Azul-gelo | `#C4E0E8` |
| Preto da marca | `#201E1E` |
| Branco | `#FFFFFF` |

Névoa, azul-gelo suave, cinzas de texto e linhas são **derivados dessas cores** por `color-mix` (variação de luminosidade/transparência) no CSS. Não introduzir outras cores (inclusive o verde do WhatsApp).

## Tipografia aprovada
**Montserrat** 400, 500, 600 e 700 (WOFF2, subconjunto latino, em `src/assets/fonts/`). Sem itálico sintético, sem outras famílias.

> Nota: uma versão anterior deste arquivo descrevia uma paleta cinza e as fontes Poppins/Inter. Esse conteúdo estava desatualizado e foi substituído pelo que está em uso e aprovado.
