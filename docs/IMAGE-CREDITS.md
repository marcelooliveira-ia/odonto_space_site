# Créditos e licenças das imagens

## Fotografias reais da equipe (`src/assets/team/`)
Fotografias de celular fornecidas pela ODONTO SPACE, tratadas (exposição, balanço de branco, contraste, recorte). Uso autorizado pela clínica; **confirmar a autorização de uso de imagem de cada profissional antes da publicação definitiva**.

| Arquivo | Pessoa | Observação |
|---|---|---|
| `dr-marcelo-souza.jpg` | Dr. Marcelo Souza (cirurgião-dentista clínico geral) | Nome confirmado pela clínica. CRO pendente. Foto substituta; trocar pelo original. |
| `ortodontista.jpg` | Ortodontista | Nome e CRO pendentes (não exibidos). |

Para trocar uma foto: substitua o arquivo mantendo o nome (proporção recomendada 4:5, mínimo 1000 px de largura).
